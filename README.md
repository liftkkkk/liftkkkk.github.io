- 🛰️ **态势感知与安全运营（Situational Awareness & Security Operations）**：以 Agentic AI 为方法论，构建感知—研判—响应的智能体工作流，驱动 Agent 执行任务、操作数据，支撑安全运营闭环

- 🧠 **知识表示与推理（KRR）→ 神经符号与知识增强推理（Neuro-symbolic & Knowledge-enhanced Reasoning）**：提出 LOM（Large Ontology Model），研究本体约束推理、GraphRAG，面向*可信 Agent 系统*
